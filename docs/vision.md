# ML System Design Trainer: Vision


LeetCode for ML System Design.

## Main philosophy

> Every decision is the result of weighing alternatives, their advantages and disadvantages.
> A system is a collection of decisions made in this way, united by a single goal.
> The goal of the designed system is to solve a business problem within given constraints. Accordingly, the system as a whole and each of its elements are aimed at achieving this goal.

Это основа продукта. Любая фича, экран, подсказка AI-помощника и формат итогового документа должны её отражать и поддерживать.

## Суть проекта

Продукт — интерактивная среда для проектирования ML-систем в формате визуального конструктора. Инженер попадает на канвас и собирает архитектурное решение блок за блоком, переключаясь между видом на систему целиком и глубокой проработкой каждого компонента. Встроенный AI-помощник, опирающийся на базу реальных system design документов, помогает на каждом шаге — от выбора альтернатив до оценки итоговой архитектуры. Результат автоматически трансформируется в структурированный документ, который можно дополнить и экспортировать.
