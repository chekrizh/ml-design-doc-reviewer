# Decisions

Журнал архитектурных решений. По философии проекта у каждого решения есть цель, альтернативы и причина выбора.

## D1. Фронтенд-стек M1

**Цель.** M1 работает целиком в браузере, без бэкенда и LLM. Нужен стек, в котором канвас и документ читают и пишут одну модель данных, а агент уверенно строит его автономно.

| Что | Выбор | Альтернативы | Почему |
|---|---|---|---|
| Основа | React + TypeScript + Vite | Vue, Svelte, Next.js | Самый распространённый стек, агент в нём сильнее всего. Типы ловят ошибки синхронизации. Next.js не нужен без бэкенда. |
| Вайтборд | `@excalidraw/excalidraw` как React-компонент | iframe на excalidraw.com, tldraw | Из iframe нельзя надёжно забрать данные. Компонент отдаёт сцену в наше хранилище и умеет `exportToSvg` для миниатюр и картинок в документе. Excalidraw выбран автором как лучший вайтборд. |
| Rich text | TipTap | Lexical, Slate, textarea + Markdown | Одинаковый редактор в Component Editor и в документе. Структурированный контент легко превратить в Markdown. |
| Состояние | Zustand | Redux Toolkit, React Context | Одно хранилище на оба режима, минимум шаблонного кода. |
| Хранилище | IndexedDB | `localStorage` | Сцены Excalidraw тяжёлые, лимита `localStorage` (~5 МБ) может не хватить. |
| Стили | Tailwind | CSS Modules, component library | Быстро повторить мокапы. |
| Экспорт MD | Генерация из модели | Конвертация HTML → MD | Модель — источник правды, вывод детерминирован и тестируем. |
| Экспорт PDF | Печать браузера с print-стилями | `pdfmake`, `jsPDF`, серверный рендер | Без тяжёлых зависимостей, текст выделяемый. Минус: системный диалог печати вместо файла в один клик. |
| Тесты | Vitest + Playwright | Jest, Cypress | Vitest нативен для Vite. Playwright даёт e2e и скриншоты для визуальной проверки агентом. |
| Пакеты | pnpm, Node 22 LTS | npm, yarn | Быстро, строгие зависимости. |
| Деплой | Статическая сборка на Vercel | GitHub Pages, Netlify | Выбор автора. |

## D2. Библиотеки для раскладки канваса и ZIP-экспорта

**Цель.** Карточки канваса перетаскиваются и меняют размер, раскладка сохраняется и сбрасывается к исходной. Markdown-экспорт с диаграммами скачивается одним архивом.

| Что | Выбор | Альтернативы | Почему |
|---|---|---|---|
| Сетка канваса | `react-grid-layout` | `dnd-kit` + своя логика ресайза, CSS grid без перетаскивания | Перетаскивание, ресайз и сериализуемая раскладка из коробки. Раскладка — простой JSON, её легко хранить в модели и сбрасывать. |
| ZIP | `JSZip` | `fflate`, `client-zip` | Самая известная, стабильный API, агент уверенно с ней работает. Размер для десятка SVG не важен. |
