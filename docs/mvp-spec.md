# MVP Spec

Status: M1 scope agreed. M2 details pending.

## Goal

Пользователь открывает интерфейс, накидывает system design в конструкторе, читает получившийся документ и при необходимости экспортирует его.

## Milestones

### M1: Canvas + Document

1. **Canvas.** Позволяет быстро накидать system design и удобно смотреть overview получившегося. Отдельный блок можно развернуть и дозаполнить.
2. **Document mode.** Полностью синхронизирован с канвасом: изменение в одном режиме сразу отображается в другом. Документ экспортируется в PDF и Markdown.

### M2: Agent checks

3. **Проверка агентом** через готовые скиллы:
   - в режиме канваса — хинты;
   - в режиме документа — комментарии, как в Google Docs.

## Decisions

- **Синхронизация: единая модель.** Документ — другое представление тех же данных. Правка Key Properties, Rationale & Notes или Trade-off Matrix в документе меняет блок на канвасе, и наоборот. Свободного текста вне блоков нет.
- **Секции: 9, начальная раскладка как на мокапе.** Карточки можно перетаскивать (менять порядок) и менять им размер. Раскладка сохраняется вместе с дизайном, кнопка «Reset layout» возвращает раскладку с мокапа. Problem Space, Evaluation (Offline), Baseline, Validation, Data & Features, Evaluation (Online), Integration, Monitoring, Target Solution & Architecture. Evaluation Strategy с мокапа переименована в Evaluation (Offline): так точнее. Порядок разделов в документе всегда канонический (этот список) и не зависит от раскладки канваса: раскладка — удобство обзора, документ — рассказ от проблемы к решению.
- **Хранение: только браузер, один дизайн.** Одно рабочее пространство с автосохранением, без списка дизайнов, без импорта и экспорта файла дизайна.
- **Диаграммы: картинка в документе.** Диаграмма Excalidraw показывается в разделе документа как изображение и попадает в PDF и Markdown. Редактируется только в блоке. Экспорт в Markdown: ZIP с `<название>.md` и папкой `images/` (SVG). Если диаграмм нет, скачивается просто `.md`.

- **Trade-offs «заполнены»,** когда в матрице ≥2 варианта, ≥1 критерий, все ячейки заполнены и один вариант отмечен выбранным. Только тогда карточка на канвасе подсвечивает trade-offs как проработанные.
- **Выбранный вариант в матрице и Key Properties независимы.** Итог пользователь сам записывает в Key Properties.
- **Аватары, Share, «Contributors» — вне MVP.** В шапке вместо них кнопки экспорта (PDF, MD).

- **Шаблонные ключи.** У секций есть предзаполненные Key Properties с пустыми значениями. Их можно переименовать, удалить или добавить свои.

  | Секция | Ключи |
  |---|---|
  | Problem Space | Domain, Business Goal, ML Task, Constraints |
  | Evaluation (Offline) | Offline Metric, Loss, Target Value |
  | Baseline | Approach, Baseline Metric |
  | Validation | — (секция может состоять только из диаграммы) |
  | Data & Features | Sources, Key Features |
  | Evaluation (Online) | Evaluation Type (например, A/B test), Key Metric |
  | Integration | Inference Pattern, Output, Latency Budget |
  | Monitoring | Data Drift, Model Quality, Alerting |
  | Target Solution & Architecture | Model Type |
- **Индикаторы на карточке.** Trade-offs и Diagram внизу карточки — индикаторы заполненности, а не кнопки. У каждого индикатора два состояния: погашен или ярко горит. Trade-offs горит только при выполнении строгого правила «trade-offs заполнены» выше, Diagram — если на вайтборде есть хотя бы один элемент. Component Editor открывается кнопкой Details.
- **Стартовое состояние.** Пустой дизайн. Кнопка «Load example» (Churn Prediction, как на мокапе) с подтверждением, потому что перезаписывает единственный дизайн. Тот же пример — фикстура для e2e-тестов.
- **Переполнение карточки.** Показываются первые 4 Key Properties и счётчик «+N».
- **Редактирование в документе — инлайн.** Key Properties, Rationale (тот же rich-text редактор) и Trade-off Matrix редактируются прямо в документе.
- **Пустые секции.** В приложении показываются с плейсхолдером «Not filled yet». В экспорт не попадают; перед экспортом предупреждение, сколько секций не заполнено.
- **Картинки в Rationale.** Кнопка в тулбаре остаётся, но пока это заглушка (неактивна, «coming soon»). Реализация позже.
- **Хранилище — IndexedDB** (сцены Excalidraw тяжёлые, лимита `localStorage` в ~5 МБ может не хватить).
- **Undo/redo.** Только нативный внутри редакторов (TipTap, Excalidraw). Глобального undo нет.
- **Язык интерфейса — английский.** Содержимое пользователь пишет на любом языке.
- **Только десктоп**, ширина от 1280px. На узких экранах заглушка «Open on desktop».
- **Деплой.** Статическая сборка, которую автор публикует на Vercel. Сборка должна деплоиться на Vercel без бэкенда.

- **Инлайн-правка на карточке.** Значения Key Properties правятся кликом прямо на карточке канваса. Ключи, Rationale, матрица и диаграмма — через Details.
- **Название дизайна** редактируется кликом в шапке («Churn Prediction (Telecom)» на мокапе — пример). В документе название становится заголовком, «ML System Architecture Spec» — подзаголовком. Из названия же берётся имя файла при экспорте.

## M1.1: правки владельца после M1

Эти решения заменяют противоречащие им решения выше.

- **Индикатор Diagram убран.** Наличие диаграммы видно по миниатюре.
- **Trade-offs — значок, а не плашка.** Весы в правом верхнем углу карточки: серые по умолчанию, зелёные с галочкой, когда выполнено строгое правило. Это статус, не кнопка. Всплывающая подсказка:
  - серые: «Trade-offs not filled yet. Weigh the alternatives and make a considered choice.»
  - зелёные: «Trade-offs filled: alternatives weighed, choice made.»
- **Details справа.** Единственная кнопка внизу карточки, прижата к правому краю.
- **Высота карточки по содержимому.** Пользователь меняет только ширину и порядок, ручка ресайза горизонтальная.
- **Safari.** Раскладка канваса в Safari такая же, как в Chrome; приёмочные тесты гоняются и в WebKit.
- **Шапка как на мокапе.** Слева логотип, название, статус сохранения мелким текстом рядом. По центру переключатель режимов. Справа AI Review, Share (всплывашка: Export PDF, Export Markdown) и меню «⋯» (Load example, Reset layout).
- **AI Review.** Всплывашка с пунктом «Full review». Пока неактивен, подсказка «Coming soon»; подключение скилла — M2.
- **Свободный текст в документе.** У каждой секции в режиме документа есть поле текста, в том числе у пустых (подсказка «Not filled yet — start typing…»). Текст попадает в Rationale & Notes секции. Пустые подсказки не печатаются и не экспортируются.
- **Заголовок документа редактируется** и меняет название дизайна.
- **Иконки секций.** Target Solution & Architecture — мишень, Baseline — якорь, Evaluation (Online) — колба (эксперимент), Problem Space — флажок. Весы используются только значком Trade-offs, чтобы не путать его с иконкой секции.
